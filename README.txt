Open index.html to preview the website on a computer.

To publish on GitHub Pages:
1. Create a public GitHub repository, for example rolandbibaj-portfolio.
2. Upload the CONTENTS of this folder (index.html, style.css, script.js and images folder) to the root of the repository.
3. In repository Settings > Pages, select Deploy from a branch, main and /(root). Save.
4. Add rolandbibaj.ch as a custom domain in Pages settings.
5. Set the DNS records at your domain registrar using the current GitHub Pages instructions shown in GitHub. Enable Enforce HTTPS after DNS is working.
